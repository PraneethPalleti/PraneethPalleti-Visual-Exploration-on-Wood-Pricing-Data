# Wood Price Data Visualization using Python and Plotly  

## Overview  
This project visualizes global timber prices and explores local vs. imported wood prices using **Plotly** and **GeoPandas**. Tree maps and scatter geo plots were created to analyze demand patterns across different regions.

## Technologies Used  
- `Plotly` – Interactive Data Visualization  
- `GeoPandas` – Geospatial Data Analysis  
- `Shapely` – Geometric Operations for Visualization  

## Features  
- Interactive tree maps visualizing timber price distributions  
- Scatter geo plots to examine demand patterns  
- Data analysis on local vs. imported wood prices  

## Results  
- Gained insights into global timber pricing trends and demand patterns.  
- Visualized geographical differences in wood prices.
